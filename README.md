# Shazam da Natureza

Código auxiliar para a apresentação "Shazam da Natureza: Identificando animais por som", apresentado na Python Brasil 2026. Apenas um wrapper [do tutorial opensoundscape](https://opensoundscape.org/en/latest/tutorials/train_cnn.html). 

## Configurando

- Crie uma [venv](https://docs.python.org/pt-br/3/library/venv.html) com o comando `python -m venv venv`
- Ative o ambiente virtual com o comando `source venv/bin/activate`
- Instale as dependências do projeto com o comando `pip install -r requirements.txt`
- Ative o ambiente do jupyter no seu terminal via `jupyterlab`
- Execute os notebooks na sequência de zero a três para baixar, processar e treinar o modelo usando opensoundscape
